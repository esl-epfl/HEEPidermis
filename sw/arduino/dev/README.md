# Development sketches (not needed for normal use)

Earlier Pico sketches used while bringing up SPI programming, kept for
reference and debugging. The supported firmware is
`../heep_programmer/heep_programmer.ino`, used with `../heep_cli.py`.

- `rpi_pico_SPI_programmer*`: earlier programmer versions (auto reset, readback, memory write tests)
- `rpi_pico_SPI_usb_diagnostic*`: USB serial throughput diagnostics
- `test_pico_clock`: external clock output test
- `programmer.py`: older Python host tool for the sketches above
