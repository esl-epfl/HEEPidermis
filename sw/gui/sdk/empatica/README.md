# Empatica SDK (placeholder)

Connection, interrogation and configuration layer for Empatica (E4) sensors
will live here. The workspace (`sw/gui/app.py`) already lists Empatica as a
device option; its checkbox shows a "Not implemented yet" panel until a
`panel.py` exposing the same interface as `../heepidermis/panel.py`
(`signals()`, `get_series()`, `invalid_spans()`, `close()`) is added.
